🚀 EXEMPLE D'UTILISATION
═══════════════════════════════════════════════════════════════════════════════

Session typique :

1. Lancer le programme :
   $ python3 bibliotheque.py

2. Ajouter un livre :
   Choisir option 1
   → Entrer ISBN, titre, auteur, année

3. Ajouter un utilisateur :
   Choisir option 5
   → Entrer ID, nom, prénom, email

4. Emprunter un livre :
   Choisir option 8
   → Entrer ISBN du livre et ID de l'utilisateur

5. Voir les statistiques :
   Choisir option 13

6. Quitter (sauvegarde automatique) :
   Choisir option 0

🐛 RÉSOLUTION DE PROBLÈMES
═══════════════════════════════════════════════════════════════════════════════

Problème : "python3: command not found"
Solution : Installer Python 3 ou utiliser "python" au lieu de "python3"

Problème : "Permission denied"
Solution : Vérifier les droits d'écriture dans le répertoire

Problème : "Erreur lors du chargement des données"
Solution : Supprimer les fichiers .json et réinitialiser avec test_bibliotheque.py
